# 🏰 像素塔防（Pixel Tower Defense）

> 网页版即时战略（RTS）塔防游戏 —— **单文件 HTML、零依赖、离线可玩、中文界面**，双击即开。

**[🎮 点击即玩](https://studyguy.github.io/pixel-tower-defense/)** · **[📦 源码仓库](https://github.com/studyguy/pixel-tower-defense)**

---

## 🕹️ 这是什么

敌人沿蜿蜒的 S 形道路一波波进攻，你在路径旁的空地上建造、升级、出售防御塔，阻止敌人抵达基地。共 **20 波进攻**、**5 种敌人**（含会回血与召唤小怪的 Boss）、**7 种防御塔**（各 3 级升级路线，随波次逐步解锁）。

整个游戏封装在**单个 `index.html`** 中：Canvas 绘制 + DOM 覆盖层 UI + Web Audio 实时合成音效，没有任何外部依赖——无需下载、无需安装、无需懂编程，浏览器打开就能玩，断网也能玩。

本项目由本人（[studyguy](https://github.com/studyguy)）通过 **Vibe Coding** 方式独立开发完成，仅供学习参考和娱乐。

## ✨ 核心特性

- **7 种塔 × 3 级升级**：箭塔（速射对空）/ 炮塔（范围轰炸）/ 冰霜（叠加减速）/ 激光（距离越远伤害越高，满射程 2.0 倍）/ 剧毒（可叠毒，第 6 波解锁）/ 闪电链（连锁 3~5 目标，第 10 波解锁）/ 狙击（400 射程一发入魂，第 13 波解锁）
- **5 种敌人**：普通 / 快速 / 重甲（抗减速 50%）/ 飞行（无视地形，仅箭塔与激光可击）/ Boss（第 5、10、15、20 波出现，每 8 秒交替回血与召唤小怪，第 20 波双 Boss）
- **20 波渐进挑战**：波次构成线性升级，敌人生命最高成长至约 9 倍；**提前开波**可拿额外金币
- **策略深度**：三种索敌策略随时切换（最前 / 最近 / 血量最高）、减速可叠加（上限 85%）、激光距离增伤
- **经济系统**：击杀金币 + 波次奖励 + **被动收入**（随波次成长）+ 出售返还 60% 总投入
- **表现**：扁平卡通 + 像素点缀，昼夜色调循环，伤害飘字、爆炸震屏，Web Audio 合成音效 + 芯片风循环 BGM（零音频文件）

## 🎯 玩法速查

### 操作

| 按键 | 功能 |
|---|---|
| `1`~`7` | 选择塔进入放置模式（再按取消）；塔随波次解锁 |
| 左键 / 右键·`ESC` | 放置塔 / 选中塔 · 取消放置 |
| `U` / `S` | 升级选中的塔 / 出售（返还 60% 总投入） |
| `空格` | 提前开始下一波（额外金币奖励） |
| `T` | 切换索敌策略：最前 → 最近 → 血量最高 |
| `P` / `M` / `Enter` | 暂停 / 静音 / 开始·重开 |

### 塔一览

| 塔 | 定位 | 解锁 | Lv.1 造价 |
|---|---|---|---|
| 🏹 箭塔 | 速射单体、可对空 | 波 1 | 60 |
| 💣 炮塔 | 范围溅射、不可对空 | 波 3 | 110 |
| ❄️ 冰霜 | 减速控场、可叠加 | 波 5 | 90 |
| 🧪 剧毒 | 持续中毒、可叠 3 层 | 波 6 | 120 |
| ⚡ 激光 | 持续射线、距离增伤、可对空 | 波 8 | 160 |
| ⚡ 闪电链 | 连锁 3~5 目标、可对空 | 波 10 | 190 |
| 🎯 狙击 | 超远程高单体、可对空 | 波 13 | 230 |

### 敌人速查

| 敌人 | 生命 | 速度 | 特征 |
|---|---|---|---|
| 普通兵 🔴 | 40 | 60 | 基础敌人 |
| 快速兵 🟡 | 25 | 105 | 高速难以拦截 |
| 重甲兵 🔵 | 150 | 38 | 高血低速、抗减速 50% |
| 飞行兵 🟣 | 32 | 95 | 直线飞向基地、免疫减速、仅箭塔/激光可击 |

## 🛠️ 技术实现

**单文件架构**（`index.html` 约 1540 行，14 个逻辑分节）：

```
<style>  布局/HUD/面板/菜单动画
<body>   画布 + HUD + 建造栏 + 选中面板 + 覆盖层菜单
<script> 配置常量 → 音频引擎 → 全局状态 → 实体类（Enemy/Tower/Projectile）
         → 特效 → 波次管理 → 游戏流程 → 主更新 → 绘制 → 输入 → UI 绑定 → 主循环
```

- **渲染**：单张 2D Canvas + devicePixelRatio 高清适配；主循环 `requestAnimationFrame`，`dt` 钳制 50ms（切后台不跳帧）
- **音频**：Web Audio 实时合成全部音效与芯片风 BGM，零音频文件
- **确定性装饰**：草地 / 路径斑点用哈希随机，刷新后地图一致
- **测试**：静态检查（`node --check` + 标签/引用校验）+ **53 项无头冒烟测试**（stub 环境驱动真实游戏逻辑，模拟约 1700 秒游戏时间，覆盖放置校验、升级边界、Boss 技能、20 波完整通关等；测试中发现并修复 2 个真实 bug）
